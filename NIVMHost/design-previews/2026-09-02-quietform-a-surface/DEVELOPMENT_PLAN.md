# Quietform A 面重设计开发方案

## 产品定义

Quietform 应该是一款 **个人专注边界与数字习惯管理 App**，归类为 Productivity，而不是一个只提供“限制开关”的工具。

它解决的核心任务是：

> 当用户进入工作、学习、休息或特定地点时，让容易分心的 App 自动进入系统 Shield 限制；同时让用户随时知道当前为何受限、何时结束，以及如何暂停或解除。

所有规则与记录默认保存在本机，不依赖账号或服务器。

## 功能契约

用户打开 App 后 3 秒内必须知道：

1. 当前是否处于专注状态。
2. 当前规则为何生效、预计何时结束。
3. 下一步最常用动作是“开始专注”还是“创建计划”。

用户必须能够完成：

1. 授权 Screen Time。
2. 选择需要管理的 App、分类或网站。
3. 立即开始一个 25、50 分钟或自定义时长的专注会话。
4. 创建按时间重复的计划。
5. 创建到达或离开地点时触发的计划。
6. 查看最近的专注记录并随时停止限制。

## 信息架构

### 首次使用

使用 3 步引导，不做营销轮播：

1. 说明 Quietform 的作用和隐私边界。
2. 请求 Family Controls 授权并选择 App。
3. 创建第一个快速会话或重复计划。

### 主导航

- **今天**：当前状态、快速开始、下一条计划、最近一次结果。
- **计划**：时间计划与地点计划的统一列表；通过筛选切换类型，不再拆成两个空页面。
- **记录**：本机记录的专注次数、持续时间和触发来源，不读取其他 App 的具体使用内容。
- **设置**：授权状态、Shield 外观、通知、隐私、帮助、版本。

### 核心对象：专注计划

一个计划包含：

- 名称，例如“深度工作”“睡前安静”。
- 受限对象：App、分类、网站。
- 触发方式：立即、时间、地点。
- 持续时间或结束条件。
- 启用状态与最近运行结果。

## Apple 原生技术方案

### 主应用

- SwiftUI + Observation。
- `AuthorizationCenter`：请求个人 Family Controls 授权。
- `FamilyActivityPicker`：让用户在系统页面选择 App、分类和网站。
- `ManagedSettingsStore.shield`：应用系统 Shield。
- Core Location Region Monitoring：地点触发。
- App Group：在主应用与扩展间共享计划、选择令牌和运行状态。

### Screen Time 扩展

1. **Device Activity Monitor Extension**
   - 使用 `DeviceActivityCenter.startMonitoring` 注册重复计划。
   - 在 `intervalDidStart` 应用 Shield。
   - 在 `intervalDidEnd` 清除该计划对应的 Shield。
   - App 退出后仍由系统执行。

2. **Shield Configuration Extension**
   - 显示 Quietform 自有图标、计划名称、结束时间和明确按钮。
   - 不访问网络，使用 App Group 中的本地状态。

3. **Shield Action Extension**
   - 处理“返回”或允许的临时暂停动作。
   - 每次动作都有可理解、可撤销的结果。

### 本地数据模型

- `FocusPlan`
- `FocusTrigger`
- `FocusSession`
- `SharedSelectionStore`
- `FocusRuntimeState`

使用 Codable 文件或本地数据库保存在 App Group；不上传用户选择令牌。

## 页面开发范围

### 1. Onboarding

- 权限未决定、拒绝、已授权三种状态。
- 授权失败时给出系统设置路径。
- 选择为空时明确下一步。
- 完成后进入“今天”，不再重复出现。

### 2. 今天

- 当前状态卡：空闲、运行中、暂停、授权异常。
- 快速会话：25 分钟、50 分钟、自定义。
- 当前会话：计划名、结束时间、剩余时间、停止按钮。
- 下一条计划。
- 最近一次完成结果。

### 3. 计划

- 时间、地点统一列表。
- 新建、编辑、启用、停用、删除、立即运行。
- 跨午夜、时区变化、定位权限丢失的异常状态。
- 删除支持确认或短时撤销。

### 4. 记录

- 最近 7 天专注总时长。
- 完成次数与计划来源。
- 按天显示本机运行记录。
- 无记录时直接引导开始第一次会话。

### 5. 设置

- Screen Time 与定位授权状态。
- Shield 外观预览。
- 通知设置。
- 数据与隐私说明。
- 清除本地记录、帮助与版本。

## 状态与无障碍

- first use、权限受限、空数据、加载、保存失败、扩展注册失败分别设计。
- 所有按钮触控区域不小于 44 pt。
- 支持 Dynamic Type、VoiceOver、深色模式、高对比度、减少动态效果与减少透明度。
- 主操作按下立即反馈；Sheet 和底部导航使用系统材质，不全页滥用玻璃。

## 开发顺序

1. 确定视觉方向并建立 `DESIGN.md`。
2. 重构共享数据模型与 App Group 存储。
3. 完成 Device Activity Monitor、Shield Configuration、Shield Action 三个扩展。
4. 完成首次引导和“今天”页面。
5. 完成计划创建、编辑及后台执行闭环。
6. 完成地点规则、记录与设置。
7. 覆盖权限、跨午夜、重启、时区变化和异常恢复测试。
8. 准备 App Store 截图、审核说明和真机操作录像。

## 完成标准

- 全新安装后，用户可以在 3 分钟内创建并运行第一条计划。
- 主应用退出后，时间计划仍能开始和结束 Shield。
- 地点规则在授权完整时可触发，并在权限变化后给出恢复路径。
- 所有核心页面不存在占位、试用、Beta 或未完成文案。
- 审核员按照审核说明无需账号或服务器即可体验完整 A 面功能。
